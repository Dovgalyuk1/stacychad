# STACYCHAD

Одностраничник под мемкоин $STACYCHAD (слияние Gigachad + Giga Stacy). Чистый HTML/CSS/JS, без сборки.

## Деплой на Vercel
1. Залить эту папку как репозиторий на GitHub (просто перетащить файлы через веб-интерфейс).
2. На vercel.com → Add New Project → Import → выбрать репозиторий. Build command не нужен, Vercel сам определит статику.
3. Когда появится контракт и соцсети — вписать их в `script.js` в блок `CONFIG` наверху файла (CA, TWITTER_URL, TELEGRAM_URL, CHART_URL).
